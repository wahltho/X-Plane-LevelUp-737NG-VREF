# Support

Support is available **only** on the
[wahltho Discord server](https://discord.gg/ySS88PMuyC).

Use that server for installation questions, bug reports and feature requests.
Do not request patch support from Zibo, LevelUp, Laminar Research, Boeing,
their official Discord servers, forums or support desks. This is an independent
community project with no affiliation, endorsement or official support.
GitHub Issues and Discussions are disabled; pull requests are not a support
channel. Support is voluntary and carries no response-time guarantee.

Include the patch version, Zibo or LevelUp/upstream version, aircraft variant,
operating system, installation method (MTK or standalone) and other installed
patches. For a VREF report, include gross weight and units, flap setting,
displayed/expected value, and concise reproduction steps. Include relevant
installer/MTK diagnostics or X-Plane Log.txt, with personal information removed.
Do not upload complete aircraft scripts, plugin binaries or copyrighted manuals.

The current package is an unvalidated experimental preview, not a production
release. Use [README.md](README.md) for the
current scope and [Documentation/PATCH_READINESS.md](Documentation/PATCH_READINESS.md)
for validation gates.
